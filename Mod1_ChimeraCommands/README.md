# Mod1：奇美拉指令平台

**可以独立使用，不需要 Capricorn / 摩羯。** 自带面板及快捷键，包内包含必要前置。
界面跟随游戏界面语言：简体中文、繁体中文，其他语言英文回退。安装目录名为 `Mod1_ChimeraCommands`，载荷为 `GameRoot`。

适配本机《赛博朋克 2077》2.5 +《往日之影》。不需要 CDPR 账号或 REDmod。

## 安装

双击 `Install.cmd`；或者把 `GameRoot` 里面的各个文件夹复制进：

`D:\steam\steamapps\common\Cyberpunk 2077`

包内已带 CET 1.38.1、RED4ext 1.31.1、redscript 0.5.32、Codeware 1.21.2、TweakXL 1.12.0、ArchiveXL 1.28.6。
安装脚本仅添加文件；遇到内容不同的同名文件会在写入前停止。

## 使用

1. 首次运行时为 CET 选一个面板按键，例如 `~`。
2. 加载存档，在室外开阔地打开 CET，找到 **CHIMERA | Command Platform**。
3. 点 **Deploy CHIMERA**。它也会加入普通呼叫载具列表（奇美拉条目是部署指令）。
4. 选择指令：
   - **FOLLOW V**：跟随，目标距离约 12 米，遇到附近敌人会迎击。
   - **GUARD HERE**：警戒当前区域，约 60 米。
   - **DESTROY CROSSHAIR TARGET**：攻击准星指定人物或车辆。
   - **STOP / HOLD**：停止攻击并待命。
   - **Recall**：召回。
5. 推荐在 CET → Bindings 中为攻击/跟随/警戒绑定按键；攻击时先瞄准，再按键。

安装 Mod2 后，可从摩羯面板或中文聊天指令发出同样的命令。

## 实现与检查结果

- 实际生成原版奇美拉 NPC，使用原版模型、武器、战斗 AI 和血量计算。
- 已在本机验证过：生成、原生移动 15 米、指定敌人后由自身战斗 AI 击倒目标。
- 当时存档测得血量约 17,335；不是固定改成这个数字。
- 最终指令版经过本机 2.5 脚本编译与代码检查。按用户要求，最后修改后未重新运行游戏。
- 原任务最后 1% 需要专用终结动作；本模组克隆在该阶段直接变成残骸。
- 车辆目标的原生武器调度、战斗阶段变化及完整警戒循环尚未逐项实机验证。
- 奇美拉体积和寻路仍受原版场景限制；狭窄街巷可能卡住，换开阔位置重新部署。
- 生成物不写进存档；读档后可重新召唤。撤除车库条目：先点 Remove entries，再保存、退出和卸载。

## 魔蜥

本包现在仅提供奇美拉。按最终要求，不再处理 Nexus 16138 的下载安装。
自制魔蜥使用桌面 `Mod3_Basilisk`，可与本模组共存。

## 卸载

先召回、Remove entries、保存并退出，再双击 `Uninstall.cmd`。
共享前置会保留，避免影响摩羯及其他模组。
