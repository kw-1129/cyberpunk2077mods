# Mod3：自制魔蜥独立兼容版

控制面板及提示跟随游戏界面语言：简体中文、繁体中文，其他语言英文回退。
安装目录为 `Mod3_Basilisk`；使用 `Install.cmd` 或复制 `GameRoot` 中的文件夹。

自制魔蜥使用独立的 `HGBasiliskSystem`。
可与 `Mod1_ChimeraCommands`、`Mod2_CapricornAI` 同时安装。

## 安装

双击 `Install.cmd`，默认目标为：
`D:\steam\steamapps\common\Cyberpunk 2077`

包内带所需共享前置。本独立版就是当前已安装的魔蜥版本。

## 使用

1. 加载存档，在室外开阔地打开 CET 面板。
2. 打开 **魔蜥 / BASILISK · 私人仓库**，点击 **部署魔蜥 / Deploy**。
3. 靠近后正常上车，或点击 **进入驾驶位 / Board**（距离不超过 35 米）。
4. 驾驶、瞄准、射击沿用游戏魔蜥键位；默认用 WASD 驾驶、鼠标瞄准，武器/下车以游戏提示和你的键位设置为准。
5. 先下车，再点 **召回 / Recall**。
6. CET → Bindings → HGBasilisk 可绑定部署、进入驾驶位、召回快捷键。

加载存档后会自动加入普通呼叫载具列表（默认长按 V）。魔蜥名称为 **魔蜥 · 私人装甲仓库**。

独立版已与另外两模组及其依赖联合编译、进行 LuaJIT 语法检查。此次安装未启动游戏。
基础魔蜥生成、驾驶位和移动曾在前一版中验证；没有额外实现飞行升降功能。

## 卸载

先下车、召回、点击 **移除车库条目**，保存退出后双击 `Uninstall.cmd`。
共享前置会保留。
