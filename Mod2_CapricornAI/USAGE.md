# 赛博朋克 2077：三个模组使用说明

## 语言与独立运行

三个控制界面自动读取游戏的**界面语言**：简体/繁体中文对应中文界面，其他语言显示英文。重新打开面板即可刷新；Bindings 内的描述在重启或 Reload all mods 后刷新。
AI 接口按游戏语言请求回复。原基础模组的剧情预设文本和语音仍是原版本。
**奇美拉不依赖摩羯**，使用 Mod1 面板或 HangarTanks 快捷键即可完成所有指令。

英文目录：`Mod1_ChimeraCommands`、`Mod2_CapricornAI`、`Mod3_Basilisk`。
安装与卸载入口：`Install.cmd` / `Uninstall.cmd`；摩羯 API：`StartAIBridge.cmd`。

## 摩羯快捷聊天（最新更新）

**重启游戏一次后，关闭 CET 覆盖层，在正常游玩时按 F10。**
屏幕右侧会出现小型聊天窗口：输入消息、点击“发送”；也可点“聊聊 / 治疗 / 跟随 / 警戒 / 停火 / 召回”。
按 **Esc**、再次按 **F10** 或点“关闭”退出。
窗口外保留游戏画面；聊天时鼠标和键盘用于聊天。

更换按键：CET → **Bindings** → **CapricornRelic** → **Capricorn: Toggle chat window / 打开关闭聊天** → 点绑定栏 → 按新按键 → 保存。
`Capricorn: offline greeting` 仍只是预设问候，不是聊天窗口。
中文输入法无法直接输入时，可在外部输入后用 **Ctrl+V** 粘贴。
API 开关仍在原摩羯 CET 面板中，离线默认可用。

CET 主窗口已恢复为折叠的小窗口。需要展开时点标题左侧小三角；拖动标题移动，拖动右下角调整大小。

## 安装位置与入口

安装目标：`D:\steam\steamapps\common\Cyberpunk 2077`

三项功能：

| 功能 | CET 面板名称 | 对应桌面安装包 |
|---|---|---|
| 奇美拉 | **CHIMERA \| Command Platform** | `Mod1_ChimeraCommands` |
| 摩羯 | **摩羯 / CAPRICORN · RELIC** | `Mod2_CapricornAI` |
| 自制魔蜥 | **魔蜥 / BASILISK · 私人仓库** | `Mod3_Basilisk` |

魔蜥已整理为 `Mod3_Basilisk`，可与另外两个模组共存。

### 第一次进入游戏

1. 使用原来的桌面快捷方式或 Steam 正常启动游戏；不需要 CDPR 账号或内置模组平台。
2. CET 首次弹出按键设置时，选一个打开/关闭面板的按键，推荐 **`~`**（Esc 下方）。
3. 加载存档，回到实际游戏画面，再按此键打开 CET。
4. 关闭 CET 面板后，鼠标和键盘恢复正常游戏操作。
5. 两台载具会在加载存档后加入普通呼叫载具列表（游戏默认 **长按 V**）。也可直接从各自模组面板部署。

模组功能快捷键默认尚未绑定，需要在 **CET → Bindings** 自行设置。菜单操作本身不依赖这些快捷键。

## 1. 自制魔蜥

在室外开阔地打开 **魔蜥 / BASILISK · 私人仓库**：

- **部署魔蜥 / Deploy**：在 V 前方约 22 米处部署。
- **进入驾驶位 / Board**：直接进入驾驶位，要求距离不超过 35 米；也可以靠近后正常上车。
- **召回 / Recall**：移除本模组生成的魔蜥；先下车才能召回。
- **加入车库 / 移除车库条目**：管理普通载具列表中的魔蜥。

驾驶与武器沿用原版魔蜥操作：默认 WASD 移动、鼠标瞄准，射击及下车以游戏提示/你的键位设置为准。
这个自制版本提供原版悬浮驾驶，没有额外加入 Nexus Flying Tank 的自由升降飞行。

快捷键分组：**CET → Bindings → HGBasilisk**，可设置部署、进入驾驶位、召回。

## 2. 奇美拉

在室外开阔地打开 **CHIMERA | Command Platform**：

| 按钮 | 功能 |
|---|---|
| **Deploy CHIMERA** | 部署奇美拉 |
| **FOLLOW V** | 跟随 V，目标距离约 12 米；迎击附近敌对人物 |
| **GUARD HERE** | 警戒当前位置周边约 60 米 |
| **DESTROY CROSSHAIR TARGET** | 攻击准星所指的人物或车辆，指令范围 180 米 |
| **STOP / HOLD** | 停火、原地待命 |
| **Recall / Recall Chimera** | 召回奇美拉 |

**攻击建议用快捷键**：先在游戏里把准星对准目标，再按你绑定的攻击键。这样不必打开面板。

快捷键分组：**CET → Bindings → HangarTanks**。

一套可自行采用的建议键位（尚未自动绑定）：

| 建议键位 | 绑定功能 |
|---|---|
| F5 | Chimera: follow V |
| F6 | Chimera: guard position |
| F8 | Chimera: destroy crosshair target |
| F9 | Chimera: cease fire / hold |

奇美拉复用原版模型、武器、战斗 AI 和血量计算。狭窄道路可能受体型/寻路影响，换开阔地重新部署。
魔蜥和奇美拉的生成物不持续写入存档，读档后重新召唤即可。

## 3. 摩羯：离线互动与技能

打开 **摩羯 / CAPRICORN · RELIC**：

- **离线聊聊**：随机预设中文回应。
- 输入框支持简单离线指令，比如：`治疗`、`短路`、`过热`、`黑墙`、`刹车`、`接管车辆`。
- 奇美拉协同：`召唤奇美拉`、`跟随`、`警戒`、`摧毁目标`、`停火`、`召回`；也可点面板下方按钮。
- 人物技能：短路、过热、义眼重启、义体失灵、武器故障、记忆清除、赛博精神病、黑墙。
- 车辆技能：制动、加速、远程接管、自毁。
- **治疗 V**、**附近敌人·黑墙**、**领取摩羯接入仓**也在面板中。
- 黑客技能以当前准星目标为对象。额外指令通过脚本直接调用效果，不耗 RAM；部分剧情实体仍可能有原生免疫。

**原模组内容**：点击“领取摩羯接入仓”，再去义体医生那里装备 Capricorn。原模组的台词、语音和互动按其装备/任务条件触发。
原模组“Call Capri”菜单的按键可在游戏 **Mod Settings → Project Capricorn** 中设置；扩展面板直接使用 CET。

当前安装的是原 Capricorn 模组加 API/互动扩展；按此前最后确认的范围，没有安装强尼模型替换。

快捷键分组：**CET → Bindings → CapricornRelic**，可绑定离线问候、黑墙、车辆制动和治疗。

## 4. 可选：连接 AI API

默认 **关闭**，离线功能不需要启动桥接器。

1. 双击桌面包里的：`Mod2_CapricornAI\StartAIBridge.cmd`。
2. 浏览器打开本机页面（默认 `http://127.0.0.1:8765`）。
3. 填写并保存：
   - 游戏目录：`D:\steam\steamapps\common\Cyberpunk 2077`
   - API Base URL：服务商的 OpenAI 兼容地址，通常以 `/v1` 结尾。
   - 模型名：服务商要求的精确模型 ID。
   - API Key：服务商密钥；本地服务可以留空。
4. 点 **测试连接**。
5. 游戏摩羯面板勾选 **启用外部 AI API**，再在消息框里聊天。
6. 如果希望 AI 指挥奇美拉或施放技能，保留 **允许 AI 调用游戏指令**。

本地接口示例：
- LM Studio：`http://127.0.0.1:1234/v1`
- Ollama：`http://127.0.0.1:11434/v1`

桥接器窗口在 API 模式期间保持开启。Key 保存在桌面包 `AIBridge/config.json`，不要把它分享出去。
API 模式会发送输入对话和简要游戏状态给你配置的服务；没有配置 Key 时不会调用收费服务。
关闭桥接器后，在游戏里取消 API 开关即可继续使用离线互动。

## 常见情况

- **看不到模组面板**：先加载存档，再打开 CET。首次先完成 CET 面板按键设置。
- **中文方框**：已预设中文字体；若原有 CET 配置覆盖了它，设置 `font.language` 为 `ChineseFull`、`font.path` 为 `C:/Windows/Fonts/simhei.ttf` 后重启游戏。
- **无法部署**：下车、退出剧情/菜单，站在室外开阔地，面向有地面的方向。
- **不能攻击**：先部署存活的奇美拉，准星对准人物或车辆，再发指令。
- **脚本报错**：日志位于游戏 `r6/logs/redscript_rCURRENT.log`；CET 模组日志在 `bin/x64/plugins/cyber_engine_tweaks/mods/对应模组目录/`。

## 卸载

先召回载具并移除对应车库条目；摩羯原接入仓/自定义快速破解先卸下。保存并退出游戏后，用各个桌面安装包中的 **Uninstall.cmd**。
共享前置保留，避免影响其余模组。

此次安装仅进行联合编译、Lua 检查和安装文件校验，没有启动游戏。安装清单保存在各模组文件夹中的 `manifest.json` 和 `installed-files.json`。
