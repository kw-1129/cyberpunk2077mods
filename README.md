# Cyberpunk 2077 Mods

**By astra**

Three installable mod packages for Cyberpunk 2077 2.5 + Phantom Liberty:

- [Chimera Commands](Mod1_ChimeraCommands/README.md) — deployment, follow, guard, attack and recall. Works independently of Capricorn.
- [Capricorn AI](Mod2_CapricornAI/README.md) — offline interactions, compact chat UI, optional AI API and Chimera coordination.
- [Basilisk](Mod3_Basilisk/README.md) — native tank deployment, boarding and driving.

**[Full English / Chinese guide and credits](Cyberpunk2077-Mods-README.md)**

Download with **Code → Download ZIP**, or clone:

```sh
git clone https://github.com/kw-1129/cyberpunk2077mods.git
```

Each package includes its dependencies. Run its `Install.cmd`, or merge the folders inside `GameRoot` into the game directory. See the full guide for custom install paths, controls and API configuration.
